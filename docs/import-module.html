1. Lab : l’import de modules

Depuis toujours, le langage Java permet d’importer des types : cela permet d’utiliser le nom simple d’un type importé au lieu de son nom pleinement qualifié.

La syntaxe est de la forme :

import nom.du.package.NomDuType;

import nom.du.package.*;

Depuis Java 5, le langage permet d’importer des membres static d’un type.

La syntaxe est de la forme :

import static nom.du.package.NomDuType.membre;

import static nom.du.package.NomDuType.*;

Le but de cette fonctionnalité est de permettre d’importer tous les types public des packages exportés par un module et ses modules transitifs.

La syntaxe est de la forme :

import module nom.du.module;
pour utiliser l’importation de module, la classe n’a pas besoin d’être explicitement dans un module.

{kb}
Modifier la classe fr.sciam.workshop.javase.importmodule.MainImportModule pour remplacer les imports des types des packages java.util et java.util.stream par un import du module java.base.

// import java.util.Arrays;
// import java.util.List;
// import java.util.stream.Collectors;
// import java.util.stream.IntStream;
import module java.base;

Compiler et exécuter la classe MainImportModule.

L’import d’un module importe aussi automatiquement ses modules déclarés comme dépendances transitives.

{kb}
Modifier la classe MainImportModule pour remplacer les imports des types des packages java.sql et javax.xml.parsers par un import du module java.sql.

// import java.sql.Connection;
// import javax.xml.parsers.SAXParser;
// import javax.xml.parsers.SAXParserFactory;
import module java.sql;

Compiler et exécuter la classe MainImportModule.

1.1. Les imports ambigus

Comme l’importation de plusieurs modules peut avoir pour effet d’importer plusieurs packages, il est possible d’avoir des collisions de noms de types : cela peut importer des types avec le même nom simple de différents packages.

{kb}
Compléter la classe fr.sciam.workshop.javase.importmodule.ImportModuleUtils pour ajouter la méthode afficher(List<String> liste, Dimension taille).

  public static void afficher(List<String> liste, Dimension taille) {
    Console console = System.console();
    if (console != null) {
      System.out.println(liste + " " + taille);
    }
  }

Ajouter les imports des modules :

  • java.base pour l’interface java.util.List

  • java.desktop pour la classe java.awt.Dimension

import module java.base;
import module java.desktop;

Compiler la classe ImportModuleUtils.

  public static void afficher(List<String> liste, Dimension taille) {

Une erreur est émise car le type List est ambigu : soit la classe java.awt.List soit l’interface java.util.List issues des 2 modules importés.

Il est possible de résoudre ce problème de deux manières :

  • Ajouter une déclaration d’importation du type unique à utiliser

    {kb}
    Modifier la classe ImportModuleUtils : après les imports de modules, ajouter l’import de l’interface

    import java.util.List;

    Compiler la classe ImportModuleUtils.

  • Ajouter une déclaration d’importation avec * sur le package contenant le type à utiliser

    {kb}
    Modifier la classe ImportModuleUtils : remplacer l’import de l’interface java.util.List par :

    import java.util.*;

    Compiler la classe ImportModuleUtils.
